# 蘇清的冷藏升级模组 / SuQing’s Refrigeration Upgrades Mod

[中文](README.md) · [English](README.en.md)

Project Zomboid **Build 42.21 单人候选版 1.0.0-rc.2-perf.1**。Mod ID：`SuQingRefrigerationUpgrade_4221`。

为现有标准可穿戴储物装备安装永久冷藏改造，保留原容量、减重、自重、外观、装备槽位、储液组件和收纳过滤。无需普通容器升级或背包超级升级前置，可与它们共用。不会返鲜。

## 安装与依赖

退出游戏并保留存档与旧版文件备份，将 `mods/SuQingRefrigerationUpgrade_4221` 整个文件夹放入用户的 `Zomboid/mods`。保留 `42` 与 `common`，先在独立单人测试档启用。不要复制整个仓库为模组目录，不要保留重复 Mod ID。

没有强制的第三方模组依赖。`loadModAfter` 为普通容器升级、EX、CleanUI、Neat Crafting 提供可选顺序提示，并不要求安装它们。原装备仍由原游戏或来源模组提供。

相关本地兼容维护见[蘇清的僵尸毁灭工程补丁合集](https://github.com/suching8848/suqing-project-zomboid-patches)。本冷藏模组没有强制依赖该仓库的某个补丁；根据实际安装的来源模组选取适用项，不要整包全部启用。原生换位与特殊装备转换仍需实际验收。

## 使用

1. 目标装备卸下、移出双手，放入主物品栏，清空普通物品；带储液组件时排空全部液体。
2. 准备非收藏材料：**6 节电池、4 电线、4 电子废料、2 小金属板**。电池按实体个数消耗，允许部分电量；没有额外技能门槛或持续耗材。
3. 原生制作 → **蘇清·冷藏升级 → 安装蘇清冷藏升级**。成功后默认开启，永久续航；取消不扣料。
4. 对已改造装备右键选择 **开启制冷 / 关闭制冷**。切换允许穿戴，但装备须处于角色主物品栏；右键不提供安装、拆除或自绘悬浮提示。
5. 拆除前同样卸下、清空、排空液体。在同一制作分类拆除，返还有效实付材料的 **50%：3 电池、2 电线、2 电子废料、1 小金属板**。电池按付款凭据保留剩余用量，不会变成满电。

目标装备可以收藏，收藏材料不支付。原容量/超级容量记录和其他 ModData 保留。

## 温度、沙盒与支持范围

常温食物的归一化温度 1 降至 0.2 约需 20 个游戏分钟；热食更久。关闭后由原生机制回温。已有 rc.1 冷藏记录、开关和电池账本继续适用，无需再次付费。

沙盒“蘇清的冷藏升级”：总开关默认开；腐坏速度 **0–100%，默认 20%**，相对世界基础腐坏速度。0 保持当前新鲜度，100 恢复常温速度，不倒退食物年龄。原生冰箱、冷冻和多层冷藏不重复相乘；不主动冻结，不修复烧焦、中毒、污染或改变生熟和吃剩量。本版不提供旧档沙盒编辑器。

自动识别有实际装备槽位的标准 `InventoryContainer`。专用弹药、枪套、钥匙、钱包过滤不取消。自定义过滤器需用允许的食物做正向确认：先放入实际允许的食物，打开菜单检查，再清空安装；不会因苹果被拒绝就推断全部食物不可放。虚拟仓库、没有实际容器的衣物口袋不保证通用支持。窄范围适配接口：`SuQingRefrigeration.RegisterContainer(fullType, true/false)`。

## 停用与验证边界

停用不会自动返料，也不删除装备、食物或改造记录。停用期间食物按普通腐坏处理；重新启用后可识别记录。需要彻底移除时，保持启用并在游戏内逐件拆除、保存退出后停用，无需覆盖世界文件。

历史记录中用户确认了 rc.1 传奇背包制冷与开关正常。rc.2/perf.1 的原生制作入口、温度渐变、世界卸载、车内、特殊转换、暂停/睡觉/加速和实际性能仍需集中游戏验收。开发记录包含 Kahlua 与本机游戏原生类离线回归；模拟负载改进不代表实机 FPS 提升。多人和专用服务器未验证。
