# 素材与来源 / Assets and provenance

中文：六个游戏PNG导出源于imagegen辅助制作的四类图标：人物头像、安装冷藏、制冷开关、拆除返料。制作分类图复用安装图，poster复用头像。角色身份参考由用户提供；本仓库只保留游戏所需导出，不复制用户原参考图、高分辨率生成图或本机生成路径。可移植提示词、尺寸及SHA-256见[素材清单](asset-manifest.json)。游戏原作及兼容模组的内容和权利归其作者。本仓库没有替第三方素材或用户参考图授予原创开源许可证。

English: Six in-game PNG exports derive from four imagegen-assisted icon types: character portrait, refrigeration installation, cooling switch and removal/refund. The crafting category reuses the installation icon, and the poster reuses the portrait. The user supplied the character reference. Only game exports are retained; the original reference, high-resolution generations and machine-local generation paths are omitted. Portable prompts, sizes and SHA-256 values are in the [asset manifest](asset-manifest.json). The game and compatible mods belong to their respective authors. This repository does not grant an original open-source license for third-party assets or the user's reference.
